自己検閲について
1. その考えは、本当に「自分」のものか

そもそも、自由意志はあるのだろうか。
「自分」の発想は、本当に自分自身から生まれたものなのだろうか。

言語を一人で作ることは不可能だ。
私たちは少なくとも、必ず他者から影響を受けて考えている。

2. 自己検閲とは何か

「自分はこういう人だ」
「こうすべきだ」
「こうしてはいけない」

これが自己検閲である。

しかも自己検閲は、ほとんど無意識に行われる。
だからこそ、自分の観念に気づかなければならない。

その観念は、自分そのものではなく、自分の周りの環境によって形成されたものだからだ。

3. 新しい言語を学ぶ

新しい言語を学ぼう。

そして、結果を求めるのではなく、感じること。
まずは感じること。

答えは、すでにそこにある。

とてもシンプルだ。

自分が「やろう」と思うなら、やってもいい。
やらなくてもいい。

世界は、自分が作ったゲームだからだ。
